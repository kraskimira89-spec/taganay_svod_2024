# Свод ФОТ и страховых взносов за 2024 год

Набор скриптов помогает собрать годовую сводную таблицу по сотрудникам:

- ФОТ за 2024 год из файла `Svodnyi-po-ZP-za-2024-god.xlsx`;
- страховые взносы из файлов `Nalogi-i-vznosy*.xlsx`;
- итоговую таблицу `Itog_personal_vznosy_2024.xlsx`.
- целевую таблицу `Personal_2024_soc_taxi.xlsx` с долями участия в соцтакси.

## Подготовка

Положите в эту папку исходные Excel-файлы:

```text
Svodnyi-po-ZP-za-2024-god.xlsx
Nalogi-i-vznosy-1.xlsx
Nalogi-i-vznosy-2.xlsx
...
```

Файлы по взносам могут быть помесячными. Главное, чтобы их имена начинались с `Nalogi-i-vznosy`.

Для **полного документального комплекта** (пояснительная записка из одного репозитория): положите PDF в **`docs/dogovory/`** по [каноническому списку имён](docs/dogovory/README.md); связка с группами расходов — в разделе **«Документальное обоснование»** ниже.

## Установка зависимостей

Откройте командную строку в папке проекта:

```bash
cd C:\taganay_svod_2024
pip install -r requirements.txt
```

## Запуск

Основной сценарий запускается одной командой:

```bash
python svod_2024.py
```

После успешного запуска будут созданы файлы:

```text
Personal_2024_auto.xlsx
Vznosy_2024_auto.xlsx
Itog_personal_vznosy_2024.xlsx
Personal_2024_soc_taxi.xlsx
```

Файл `Personal_2024_soc_taxi.xlsx` содержит:

- ФИО;
- категорию участия;
- долю участия в соцтакси;
- ФОТ за 2024 год;
- страховые взносы за 2024 год;
- итог ФОТ + взносы;
- сумму, отнесённую на соцтакси.
- лист `Группа_затрат_2024` с агрегированной таблицей для пояснительной записки.

Сотрудники, которые не входят в матрицу участия в соцтакси, автоматически помечаются как `Другая деятельность (Роснефть/прочее)` с долей участия `0`.

Группы затрат формируются автоматически:

- `1. ФОТ водителей и соцработников`;
- `2. ФОТ диспетчера`;
- `3. ФОТ ремонтного персонала (Егоров, Шакалов, Родионов)`;
- `4. ФОТ руководителя соцслужбы (Лопакова Н.Ф.)`;
- `5. ФОТ руководителя организации (50% Богдановского)`;
- `6. ФОТ бухгалтерии, IT и админ-персонала`;
- `0%. Другая деятельность (Роснефть/прочее)`.

## Как воспроизвести расчёт тарифа за 2024 год с нуля

Один и тот же порядок можно повторить на чистой копии проекта, чтобы показать **проверяемость и воспроизводимость** расчёта (ФОТ, прочие расходы по 60-й, сверка с 76-й).

Предполагается, что выполнены разделы **«Подготовка»** и **«Установка зависимостей»**, рабочая папка — `C:\taganay_svod_2024`.

| Шаг | Действие |
|-----|----------|
| 1 | Распаковать архив с ОСВ (например `ОСВ и свод.zip`) в `_extract_osv`. |
| 2 | `python scripts/rename_extract_osv_files.py` — появятся `Osv_schet_60_2024.xls`, `Osv_schet_76_2024.xls` и др. |
| 3 | `python svod_2024.py` — `Personal_2024_soc_taxi.xlsx`, листы по ФОТ и группам. |
| 4 | `python svod_osv60.py --year 2024` → `Osv60_soc_taxi_2024.xlsx`. Для 2025: `python svod_osv60.py --year 2025`. |
| 5 | `python svod_reconcile_osv76.py --year 2024` → `Osv76_sverka_2024.xlsx` (свой файл: `--osv "…\файл.xlsx"`). |
| 6 | `python svod_osv60.py --year 2025` и `python svod_reconcile_osv76.py --year 2025` — при наличии ОСВ за 2025. |
| 7 | `python compare_osv60.py` → `Svod_60_2024_2025.xlsx` (сравнение строк записки по счёту 60). |

**Правила по счёту 60:** в сырой выгрузке 1С обычно **нет** колонки «Статья расходов» — тогда классификация только по **контрагенту** (`svod_osv60_core.py`). Если добавили столбец со статьёй: `python svod_osv60.py --year 2024 --article-col 7` (0-based; колонка H = 7). Ключевые слова по статье — `config_osv60.py`.

## Воспроизводимый pipeline (2024 / 2025)

Одинаковая логика для двух лет: сначала переименование ОСВ, затем ФОТ, затем счёт 60 и сверка 76.

```bash
cd C:\taganay_svod_2024
pip install -r requirements.txt
python scripts/rename_extract_osv_files.py
python svod_2024.py
python svod_osv60.py --year 2024
python svod_reconcile_osv76.py --year 2024
python svod_osv60.py --year 2025
python svod_reconcile_osv76.py --year 2025
python compare_osv60.py
```

**Где исходники:** сводная ЗП и взносы — в **корне** проекта (`Svodnyi-po-ZP-za-2024-god.xlsx`, `Nalogi-i-vznosy*.xlsx`); выгрузки ОСВ из 1С — в **`_extract_osv`** (после `rename_extract_osv_files.py` — имена вида `Osv_schet_60_2024.xls`).

**Что на выходе (основное):**

| Файл | Назначение |
|------|------------|
| `Personal_2024_soc_taxi.xlsx` | ФОТ+взносы, доли соцтакси; листы `Персонал_2024_soc_taxi`, `Группа_затрат_2024` |
| `Osv60_soc_taxi_{год}.xlsx` | Прочие расходы по 60: см. листы ниже |
| `Osv76_sverka_{год}.xlsx` | Сверка физлиц ОСВ 76 с персоналом (`Сверка_76`, `Справочник_ФИО`) |
| `Svod_60_2024_2025.xlsx` | Сравнение групп записки 2024 vs 2025 (`Сравнение_60`) |

**Листы `Osv60_soc_taxi_{год}.xlsx`:**

| Лист | Содержание |
|------|------------|
| `Строки_ОСВ60` | Контрагент, обороты, статья (если была в файле), группа, сумма на соцтакси |
| `Свод_по_группам` | Агрегат по внутренней группе: сумма кредита оборота и сумма на соцтакси |
| `Не_включено_в_свод` | Строки без правила классификации / банки |
| `Группа_затрат_записка` | 7 строк + итог для вставки в пояснительную записку |

Скрипт **`svod_osv60.py`** внутри строит отчёт через функции `load_osv60` → `build_svod` → таблица записки → `save_report` (см. модуль `svod_osv60.py`). Правила по статьям — `config_osv60.py`, по контрагентам — `svod_osv60_core.py`. **Доля косвенных (k)** по годам — `config_allocation.py` (источник: приходы по соцуслугам, не счёт 62); для ФОТ админ‑части в `svod_2024.py` используется тот же коэффициент за 2024 год.

## Документальное обоснование

Пояснительная записка для суда воспроизводима из одного репозитория, если в каталоге **`docs/dogovory/`** лежат PDF по [каноническому списку](docs/dogovory/README.md). Ниже — связка **строк листа `Группа_затрат_записка`** (`svod_osv60_core.py`) с документами; машинный расчёт — в **`Osv60_soc_taxi_{год}.xlsx`**.

### Прочие расходы по счёту 60 (7 строк записки)

| № записки | Группа в пояснительной записке | Внутренние группы (`config_osv60.py`) | Документы (PDF в репозитории) |
|-----------|-------------------------------|----------------------------------------|------------------------------|
| 1 | Аренда специализированного транспортного средства и гаража | `Аренда автомобиля`, `Аренда гаража/стоянки` | [Договор аренды VW + допсоглашение](docs/dogovory/dogovor-arenda-volkswagen-lopakova-dopsoglashenie.pdf); при необходимости обоснования парка — [КП ГАЗель NEXT](docs/dogovory/kp-gazel-next.pdf) |
| 2 | Расходы на топливо (ГСМ) | `Топливо (ГСМ)` | Первичка по контрагентам сверяется с листом `Строки_ОСВ60`; при наличии — договоры с поставщиками ГСМ в `docs/dogovory/` (произвольное имя, см. [dogovory/README](docs/dogovory/README.md)) |
| 3 | Текущий ремонт, обслуживание и автотовары | `Ремонт и обслуживание автомобиля` | Договоры со СТО / накладные (по мере добавления в `docs/dogovory/`) |
| 4 | Страхование транспортных средств | `Страхование автомобиля` | Полисы ОСАГО и иные (по мере добавления в `docs/dogovory/`) |
| 5 | Медицинские осмотры водителей | `Медосмотр водителей` | Договор с медорганизацией (по мере добавления в `docs/dogovory/`) |
| 6 | Мойка автомобилей и санитарное состояние | `Мойка автомобилей` | Договор с мойкой (по мере добавления в `docs/dogovory/`) |
| 7 | Прочие эксплуатационные (косвенные, × доля выручки по соцуслугам) | `Коммунальные услуги`, `Связь, IT и офисные расходы`, `Прочие эксплуатационные` | [ОСВ 60 за 2024 (PDF)](docs/dogovory/osv-60-2024.pdf) — согласование итогов учёта; [сводный отчёт по поездкам](docs/dogovory/svodnyi-otchet-poezdki-sottaksi.pdf) — доля **78%** за 2024 (**76%** за 2025 — см. `config_allocation.py`); договоры на связь, аренду помещений и т.д. — по мере добавления |

Сводная **выгрузка 1С** по счёту 60 в формате Excel остаётся в **`_extract_osv/Osv_schet_60_{год}.xls`** — она участвует в скриптах; PDF в `docs/dogovory/` дублирует учёт для приложения к материалам суда.

## Если скрипт не находит колонки

Запустите вспомогательный скрипт:

```bash
python debug_svod.py
```

Он покажет реальные названия листов и колонок в файле `Svodnyi-po-ZP-za-2024-god.xlsx`. После этого можно поправить названия колонок в `svod_2024.py`.

## ОСВ по счёту 60 (прочие расходы для записки)

Кратко: распакуйте выгрузки в `_extract_osv`, при необходимости `python scripts/rename_extract_osv_files.py`, затем универсальная команда:

```bash
python svod_osv60.py --year 2024
python svod_osv60.py --year 2025
```

Полный порядок с ФОТ и сверкой 76 — в разделе **«Воспроизводимый pipeline»** и **«Как воспроизвести расчёт тарифа за 2024 год с нуля»**.

Параметры: `--osv-path`, `--output`, `--article-col` (см. `python svod_osv60.py -h`).

**«Верная» ОСВ из бухгалтерии** (12 колонок, статья расходов справа от сумм) — столбец статьи **определяется автоматически** (обычно индекс 7). Пример с вашим путём:

```bash
python svod_osv60.py --year 2024 --osv-path "E:\ЦИП Таганай\6-БУХГАЛТЕРИЯ\Оборотно-сальдовые ведомости\Оборотно-сальдовая ведомость верная по счету 60 за 2024 г.xls"
```

Чтобы подтянуть «верные» файлы из бухгалтерии в `_extract_osv` без длинных `--osv-path`:

- **60 за 2024:** `python scripts/sync_osv60_vernaya_2024.py` (`OSV60_VERNAYA_2024` при необходимости).
- **60 за 2025:** `python scripts/sync_osv60_vernaya_2025.py` (`OSV60_VERNAYA_2025`); исходник по умолчанию — `ОБС верно по счету 60 за 2025 г.xls`.
- **70 за 2025** (архив в проекте, свода по 70 пока нет): `python scripts/sync_osv70_vernaya_2025.py` (`OSV70_VERNAYA_2025`); копия как `Osv_schet_70_2025.xls`.
- **Банковские выписки** (Сбер, ВТБ, 2024–2025): `python scripts/sync_bank_vypiski.py` → `docs/bank_vypiski/` (`BANK_VYPISKI_*` при необходимости).

Результаты: `Osv60_soc_taxi_2024.xlsx` / `Osv60_soc_taxi_2025.xlsx` — см. раздел **«Листы Osv60_soc_taxi»** выше. После переименования в `_extract_osv` также появляется `Svod_finansovye_pokazateli_2024.xlsx`.

**Сравнение 2024 и 2025:** `python compare_osv60.py` → `Svod_60_2024_2025.xlsx`.

Копия свода из папки отчётов (`ОСВ и свод/Свод 2024-2025 .xlsx`): `python scripts/sync_svod_2024_2025_from_otchety.py` → в корне проекта **`Svod_2024_2025_iz_arhiva_OSV_i_svod.xlsx`** (это не то же самое, что машинный `Svod_60_2024_2025.xlsx` из `compare_osv60.py`).

В свод попадают только строки с известным правилом (остальное — на лист исключений). Топливом по контрагенту считаются **Ликард** и **Газпромнефть** (АЗС); прочие «Газпром*» — **коммунальные**; на косвенные расходы применяется доля приходов по соцуслугам из **`config_allocation.py`** (**2024:** **0,78**; **2025:** **0,76** — не из счёта 62). Правки по статьям — `config_osv60.py`, по контрагентам — `svod_osv60_core.py`.

## Сверка ОСВ по счёту 76 с персоналом

После `rename_extract_osv_files.py` и наличия `Personal_2024_soc_taxi.xlsx`:

```bash
python svod_reconcile_osv76.py --year 2024
python svod_reconcile_osv76.py --year 2025
```

По умолчанию читается `Personal_2024_soc_taxi.xlsx` (лист `Персонал_2024_soc_taxi`); для другого файла: `--personal`. Свой Excel с колонкой «роль»: `--osv "…\файл.xlsx" --sheet-osv Лист1`.

## Пакет для Perplexity / внешнего ИИ

Один архив с исходниками, результатами расчётов и кодом (для составления отчётов и пояснительной записки):

```bash
python scripts/build_perplexity_bundle.py
```

В корне появится **`Perplexity_paket_Taganay_2024_2025.zip`** (внутри папка `taganay_perplexity_2024_2025/` и **`MANIFEST.txt`** со списком файлов).

## Старые скрипты

- `svod_personal.py` — отдельная сборка ФОТ.
