# Свод ФОТ и страховых взносов за 2024 год

Набор скриптов помогает собрать годовую сводную таблицу по сотрудникам:

- ФОТ за 2024 год из файла `Svodnyi-po-ZP-za-2024-god.xlsx`;
- страховые взносы из файлов `Nalogi-i-vznosy*.xlsx`;
- итоговую таблицу `Itog_personal_vznosy_2024.xlsx`.
- целевую таблицу `Personal_2024_soc_taxi.xlsx` с долями участия в соцтакси.

## Подготовка

Положите в эту папку исходные Excel-файлы:

```text
Svodnyi-po-ZP-za-2024-god.xlsx
Nalogi-i-vznosy-1.xlsx
Nalogi-i-vznosy-2.xlsx
...
```

Файлы по взносам могут быть помесячными. Главное, чтобы их имена начинались с `Nalogi-i-vznosy`.

## Установка зависимостей

Откройте командную строку в папке проекта:

```bash
cd C:\taganay_svod_2024
pip install -r requirements.txt
```

## Запуск

Основной сценарий запускается одной командой:

```bash
python svod_2024.py
```

После успешного запуска будут созданы файлы:

```text
Personal_2024_auto.xlsx
Vznosy_2024_auto.xlsx
Itog_personal_vznosy_2024.xlsx
Personal_2024_soc_taxi.xlsx
```

Файл `Personal_2024_soc_taxi.xlsx` содержит:

- ФИО;
- категорию участия;
- долю участия в соцтакси;
- ФОТ за 2024 год;
- страховые взносы за 2024 год;
- итог ФОТ + взносы;
- сумму, отнесённую на соцтакси.
- лист `Группа_затрат_2024` с агрегированной таблицей для пояснительной записки.

Сотрудники, которые не входят в матрицу участия в соцтакси, автоматически помечаются как `Другая деятельность (Роснефть/прочее)` с долей участия `0`.

Группы затрат формируются автоматически:

- `1. ФОТ водителей и соцработников`;
- `2. ФОТ диспетчера`;
- `3. ФОТ ремонтного персонала (Егоров, Шакалов, Родионов)`;
- `4. ФОТ руководителя соцслужбы (Лопакова Н.Ф.)`;
- `5. ФОТ руководителя организации (50% Богдановского)`;
- `6. ФОТ бухгалтерии, IT и админ-персонала`;
- `0%. Другая деятельность (Роснефть/прочее)`.

## Если скрипт не находит колонки

Запустите вспомогательный скрипт:

```bash
python debug_svod.py
```

Он покажет реальные названия листов и колонок в файле `Svodnyi-po-ZP-za-2024-god.xlsx`. После этого можно поправить названия колонок в `svod_2024.py`.

## Старые скрипты

- `svod_personal.py` — отдельная сборка ФОТ.
- `svod_vznosy.py` — отдельная сборка взносов по одному файлу.
- `debug_svod.py` — диагностика колонок.

Для обычной работы используйте `svod_2024.py`.
