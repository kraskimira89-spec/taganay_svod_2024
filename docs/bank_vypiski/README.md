# Банковские выписки (копии для репозитория)

Файлы подтягиваются скриптом из сетевых путей на `E:\`:

```bash
python scripts/sync_bank_vypiski.py
```

| Подпапка | Содержимое |
|----------|------------|
| `sber/` | СберБизнес: выписки за **2024** и **2025** (PDF). |
| `vtb/` | ВТБ: выписки **2024** и **2025** (PDF и XLSX), исходные имена файлов сохранены. |

Пути по умолчанию заданы в `scripts/sync_bank_vypiski.py`; при переносе диска используйте переменные `BANK_VYPISKI_SBER_2024`, `BANK_VYPISKI_SBER_2025`, `BANK_VYPISKI_VTB_DIR`.
