# Заявки ГКУ ЦСТ (соцтакси) и связь с «сводным отчётом»

## Назначение

Файл **`Заявки {год}.xls`** — выгрузка реестра заявок для отчётности в **ГКУ ЦСТ** (папка `3-Отчеты в ГКУ ЦСТ {год}` на диске организации).

Отчёт **«отчет Таганай — сводный за {год}.pdf»** (папка `Отчеты 2024 год` / аналог за 2025) — **итоговая форма** по оказанным услугам и субсидии для получателей.

Связь методическая, не автоматическая:

| Источник | Что считаем | Для чего |
|----------|-------------|----------|
| `Заявки_*.xls` | строки заявок, даты **времени отправления** / **даты заявки**, поставщик | операционный объём, помесячная динамика, разрез по поставщику |
| Сводный PDF | поездки/услуги и суммы по получателям | сверка с отчётностью и субсидией |

Числа **не обязаны** совпадать один в один: в заявках есть отмены, переносы, строки без фактического `Время отправления`, в PDF — агрегат по другому срезу. Сверка делается **по контрольным итогам** и выборочно по периодам.

## Файлы в репозитории

После команды импорта (см. ниже):

- `data/gku_cst/{год}/Заявки_{год}.xls` — копия исходника;
- `data/gku_cst/{год}/zayavki_{год}_svod.xlsx` — свод (листы **по_месяцам**, **по_поставщику**, **контроль**);
- `data/gku_cst/{год}/zayavki_{год}_po_mesyacam.csv`, `zayavki_{год}_po_postavschiku.csv` — выгрузки для внешних инструментов.

## Команда

Из корня репозитория:

```text
python scripts/export_zayavki_gku_cst.py --year 2025 --import-from "E:\ЦИП Таганай\СОЦИАЛЬНЫЕ УСЛУГИ\Соцтакси\3-Отчеты в ГКУ ЦСТ 2025\Заявки 2025.xls"
```

Повторный пересчёт без копирования (если `.xls` уже в `data/gku_cst/2025/`):

```text
python scripts/export_zayavki_gku_cst.py --year 2025
```

## Исходники на диске E: (эталонные пути)

- Заявки 2025: `E:\ЦИП Таганай\СОЦИАЛЬНЫЕ УСЛУГИ\Соцтакси\3-Отчеты в ГКУ ЦСТ 2025\Заявки 2025.xls`
- Заявки 2024: `E:\ЦИП Таганай\СОЦИАЛЬНЫЕ УСЛУГИ\Соцтакси\3-Отчеты в ГКУ ЦСТ 2024\Заявки 2024.xls`
- Сводный отчёт (пример 2024): `E:\ЦИП Таганай\Суд\ДСЗН 2025 по тарифу соцтакси\Отчеты 2024 год\отчет Таганай - сводный за 2024.pdf`
