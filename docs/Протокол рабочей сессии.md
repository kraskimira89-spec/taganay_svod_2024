8. Методологические решения сессии
Счёт 62 не используется для расчёта доли. Коэффициент берётся из приходов по соцуслугам.

Счёт 76 — только сверочный, в себестоимость не включается (избежание задвоения).

Богдановский С.В. — 50% участия × k_выручки.

Лопакова Н.Ф. — 50% участия (адм. соцтакси), без умножения на k.

20 сотрудников Роснефть/прочее — автоматически 0%.

Амортизация автотранспорта — 100% на соцтакси (машины используются только для услуги).

Аренда Volkswagen Caddy (1 080 000 руб./год) — 100% на соцтакси, договор № 01‑20.
