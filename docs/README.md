# Документы к пояснительной записке

Сканированные договоры и первичка — в **`dogovory/`** (см. [dogovory/README.md](dogovory/README.md)).

**Банковские выписки** (Сбер, ВТБ) — в **`bank_vypiski/`** (см. [bank_vypiski/README.md](bank_vypiski/README.md)); обновление копий: `python scripts/sync_bank_vypiski.py`.

Имена «канонических» PDF в `dogovory/` зафиксированы в README там же, чтобы ссылки из корневого `README.md` не ломались после добавления файлов.

## Протокол и финальные материалы для суда

- Итоги рабочей сессии, цифры и решения: [Протокол рабочей сессии.md](Протокол%20рабочей%20сессии.md).
- **PDF** договоров, соглашений заказчика, ОСВ в сканах — загрузка в **`dogovory/`** (в т.ч. нумерованные подпапки) и коммиты вручную.
- **Итоговая пояснительная записка в Word** с приложениями — оформляется вне репозитория или выкладывается в `docs/` по решению организации (рекомендуется не хранить огромные бинарники в публичном Git без LFS).
