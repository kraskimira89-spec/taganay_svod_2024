# Канонические PDF для репозитория

Положите сюда файлы **ровно с такими именами** (или переименуйте при копировании из бухгалтерии):

| Файл | Назначение |
|------|------------|
| `osv-60-2024.pdf` | Оборотно-сальдовая ведомость по счёту 60 за 2024 (скан/выгрузка в PDF) — сверка с листом `Группа_затрат_записка` в `Osv60_soc_taxi_2024.xlsx`. |
| `svodnyi-otchet-poezdki-sottaksi.pdf` | Сводный отчёт по поездкам социального такси — обоснование доли выручки по соцуслугам (в т.ч. **78%** за 2024). |
| `kp-gazel-next.pdf` | Коммерческое предложение на **ГАЗель NEXT** (обоснование закупки/эксплуатации спецтранспорта). |
| `dogovor-arenda-volkswagen-lopakova-dopsoglashenie.pdf` | Договор аренды **Volkswagen** у **Лопаковой Н.Ф.** с допсоглашением (например **90 000 руб./мес.** → **1 080 000 руб./год** в соответствии со строкой «аренда автомобиля» в ОСВ 60). |

Дополнительные договоры (СТО, ОСАГО, мойка, связь, аренда помещений и т.д.) можно добавлять с говорящими именами, например `dogovor-sto-remont-2024.pdf`, и кратко описать их в разделе **«Документальное обоснование»** в корневом `README.md`.
