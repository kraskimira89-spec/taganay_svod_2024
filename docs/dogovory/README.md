# Договоры и подтверждающие документы (ОСВ‑60)

## Структура по подпапкам (для суда и GitHub)

Рекомендуемая раскладка PDF (можно наполнить вручную или скриптом `python scripts/sync_dogovory.py`):

```text
docs/dogovory/
├── arenda/          # аренда VW, гараж, допсоглашения
├── toplivo/         # ЛИКАРД, Газпромнефть
├── remont/          # СТО, запчасти, КАФФА и т.п.
├── strakhovanie/    # РЕСО, полисы
├── medosmotr/       # медорганизации
├── svyaz_it/        # связь, IT, картриджи
├── kommunalka/      # ЖКХ, вывоз, энергосбыт
├── kp_avtotransport/# КП ГАЗель NEXT и аналоги
└── other/           # не сопоставилось автоматически (sync_dogovory)
```

Источник для `sync_dogovory.py`: переменная **`DOGOVORY_SOURCE`** (папка с PDF на диске). По умолчанию пробуется `E:\ЦИП Таганай\Договоры`.

Для уже готовых файлов `Osv60_soc_taxi_*.xlsx` колонку **«Внутренняя_группа»** на листе **«Не_включено_в_свод»** можно заполнить скриптом (та же логика, что в `svod_osv60_core.classify_row`): `python scripts/fill_osv60_skipped_vnutr_gruppa.py`.

## Сопоставление с группами расходов (ОСВ‑60)

| Группа расхода (логика свода) | Контрагент / тема | Пример пути в репозитории |
|------------------------------|-------------------|---------------------------|
| Аренда автомобиля | Лопакова Н.Ф., VW Caddy | `arenda/…Lopakova…pdf`, договор № 01‑20 |
| Аренда гаража / стоянки | Норчак и др. | `arenda/…garazh…pdf` |
| Топливо (ГСМ) | ЛИКАРД, Газпромнефть | `toplivo/Dogovor_LIKARD.pdf` и т.п. |
| Ремонт автомобиля | АЛЬТЕРНАТИВА, КАФФА, Тимченко… | `remont/…` |
| Страхование | РЕСО‑ГАРАНТИЯ | `strakhovanie/Polis_RESO.pdf` |
| Медосмотр | БУДЬ ЗДОРОВ!, Сибирское здоровье | `medosmotr/…` |
| Связь, IT | Т2, КБ, REG.RU и т.д. | `svyaz_it/…` |
| Коммунальные / эксплуатация | СЕВЭНКО, ЭК ВОСТОК, ЯмалЭкология… | `kommunalka/…` |
| Обоснование стоимости транспорта | КП ГАЗель NEXT | `kp_avtotransport/KP_GAZel_NEXT.pdf` |

Имена в таблице — ориентир; фактические имена файлов могут совпадать с уже загруженными PDF (в т.ч. с кириллицей и номерами договоров).

## Канонические имена в корне `docs/dogovory/` (ссылки из корневого README)

Для стабильных ссылок в **«Документальное обоснование»** можно **дополнительно** положить копии с фиксированными именами:

| Файл | Назначение |
|------|------------|
| `osv-60-2024.pdf` | ОСВ по счёту 60 за 2024 (PDF). |
| `svodnyi-otchet-poezdki-sottaksi.pdf` | Сводный отчёт по поездкам соцтакси (доля выручки). |
| `kp-gazel-next.pdf` | КП на **ГАЗель NEXT**. |
| `dogovor-arenda-volkswagen-lopakova-dopsoglashenie.pdf` | Договор аренды VW у Лопаковой Н.Ф. + допсоглашение. |

Остальные договоры — в подпапках выше или с говорящими именами в `other/`.
